## Теоретические сведения

### Что такое соль (Salt)?

**Соль** — это случайная строка данных, которая добавляется к паролю перед хешированием. Соль генерируется индивидуально для каждого пользователя и сохраняется вместе с хешем.

### Принцип работы хеширования с солью

**Без соли:**
hash = SHA-256(password)

**С солью:**
hash = SHA-256(password + salt)

Где:
- **password** — пароль пользователя
- **salt** — случайная строка (обычно 16 байт)

### Свойства безопасного хранения паролей

- **Необратимость** - Из хеша невозможно восстановить исходный пароль 
- **Уникальность** - Одинаковые пароли дают разные хеши (при использовании соли) 
- **Лавинный эффект** - Изменение 1 бита пароля меняет весь хеш 
- **Стойкость к атакам** - Соль защищает от rainbow-таблиц 

### Почему недостаточно SHA-256:

- **Rainbow-таблицы** — предвычисленные таблицы хешей для быстрого подбора паролей
- **Атака перебором** — можно перебирать все возможные пароли
- **Одинаковые пароли → одинаковые хеши** — злоумышленник видит, у кого одинаковые пароли

Соль решает эти проблемы, делая каждый хеш уникальным.
